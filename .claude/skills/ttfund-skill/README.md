# 天天基金综合技能包 (ttfund-skill)

这是一个综合性的基金信息查询技能包，整合了天天基金的多种API能力，支持通过自然语言查询各类基金相关信息。

## 功能特性

- **多合一查询**：整合10种不同的基金相关查询功能
- **自然语言支持**：通过自然语言即可完成各种查询
- **全面覆盖**：涵盖基金、经理、持仓、净值、指数、黄金等多个维度
- **智能解析**：自动解析用户意图并调用相应API

## 支持的查询类型

### 基础信息类
- 基金基础信息查询
- 基金经理信息查询
- 基金净值查询
- 基金持仓查询

### 分析选基类
- 条件选基
- 指数详情查询
- 投顾策略查询

### 特色服务类
- 黄金行情分析
- 模拟组合管理
- 自选基金查询

## 配置要求

1. 需要获取天天基金API密钥：
   - 打开天天基金App
   - 搜索 `skills`
   - 获取对应的API密钥

2. 设置环境变量：
```bash
export TTFUND_APIKEY="your_api_key_here"
```
