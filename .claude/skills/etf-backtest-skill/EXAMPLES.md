# ttfund-skill 使用示例

## 环境准备

首先确保设置了环境变量：

```bash
export TTFUND_APIKEY="your_actual_api_key_here"
```

## 查询示例

### 1. 基金信息查询

**用户输入**: "查询华夏成长混合基金信息"

**技能处理**:
- 识别查询类型：基金基础信息
- 提取基金代码/名称：华夏成长混合
- 构建请求:
```json
{
  "skill_id": "FUND_BASE_INFOS",
  "_skill_version": "1.1.0",
  "fcode": "000001"
}
```

### 2. 基金经理查询

**用户输入**: "张坤管理的基金有哪些？"

**技能处理**:
- 识别查询类型：基金经理信息
- 提取基金经理姓名：张坤
- 构建请求:
```json
{
  "skill_id": "FUND_MANAGER_INFO",
  "_skill_version": "1.0.0",
  "manager_name": "张坤"
}
```

### 3. 条件选基

**用户输入**: "近一年收益率最高的5只基金"

**技能处理**:
- 识别查询类型：条件选基
- 设置排序参数：按近一年收益率倒序
- 构建请求:
```json
{
  "skill_id": "FUND_CONDITION_SELECT",
  "_skill_version": "1.1.0",
  "pageIndex": 1,
  "pageNum": 5,
  "pageType": 1,
  "orderField": "5_6_-1"
}
```

### 4. 基金持仓查询

**用户输入**: "000001 基金的持仓情况"

**技能处理**:
- 识别查询类型：基金持仓
- 提取基金代码：000001
- 构建请求:
```json
{
  "skill_id": "FUND_HOLDING_INFO",
  "_skill_version": "1.0.0",
  "fund_id": "000001",
  "holding_type": "all"
}
```

### 5. 黄金行情查询

**用户输入**: "今天黄金行情怎么样？"

**技能处理**:
- 识别查询类型：黄金分析
- 构建请求:
```json
{
  "skill_id": "FUND_HUAAN_GOLD_INFO",
  "_skill_version": "1.0.0",
  "query_scope": "all"

```

### 6. 指数详情查询

**用户输入**: "沪深300指数现在多少点？"

**技能处理**:
- 识别查询类型：指数详情
- 提取指数名称：沪深300

```json
{
  "skill_id": "FUND_INDEX_INFO",
  "_skill_version": "1.0.0",
  "index_id": "沪深300",
  "query_scope": "all",

```

### 7. 基金净值查询

**用户输入**: "华夏成长混合近三年的净值走势"

**技能处理**:
- 识别查询类型：基金净值
- 提取基金名称：华夏成长混合
- 设置时间范围：近三年
- 构建请求:
```json
{
  "skill_id": "FUND_NAV_INFO",
  "_skill_version": "1.0.0",
  "fund_id": "000001",
  "range": "3n"
}
```

## 错误处理示例

### 缺少API密钥

**提示信息**: 
```
当前未检测到 TTFUND_APIKEY，请先前往天天基金搜索 skills 获取 apikey，
并在本机配置该环境变量后重试。
```

### 查询无结果

**提示信息**:
```
未能找到相关的基金信息，请检查基金代码或基金名称是否正确。
```

## 投资提示

1. **风险提示**: 基金投资有风险，过往业绩不代表未来表现
2. **分散投资**: 建议根据自身风险承受能力合理配置资产
3. **长期投资**: 基金适合长期投资，请避免频繁买卖
4. **理性投资**: 投资决策应基于充分的信息和理性分析
