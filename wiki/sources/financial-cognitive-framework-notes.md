# 金融认知与分析框架笔记

## 摘要
一份关于金融市场核心认知、分析框架、估值方法和大类资产定价的综合性笔记，涵盖了从宏观分析到具体投资策略的全方位内容。

## 关键要点
- 价格=f(成交量，时间，空间，人，认知) - 金融市场定价的核心函数
- 无套利均衡理论：金融市场定价 = 成本 + 时间价值 + 机会补偿
- IPO思维模型：O = P(I)，即输出基于输入的处理模型
- 投资三看理论：长期看人口，中期看政策，短期看金融
- 大类资产定价底层逻辑：股票看重未来盈利，大宗看重当下供需，债券看机会成本
