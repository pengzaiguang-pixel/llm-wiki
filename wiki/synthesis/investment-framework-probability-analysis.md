# 投资框架与概率分析体系

## 概述

本页面总结了一套完整的投资分析框架，涵盖从宏观周期到微观操作的多层次分析体系。该框架强调概率思维、动态预判和风险控制，旨在构建可持续的投资决策系统。

## 核心理念

### 概率思维
- 投资本质上是一场概率游戏，期望值为正的策略才值得下注
- 公式：`bp - q > 0`，其中b为赔率，p为胜率，q为失败概率
- 收益公式：`收益 = 次数N × 本金C × (胜率P×止盈 - (1-胜率P)×止损) × 杠杆系数`

### 动态预判
- 面向未来，低买高卖
- 因果分析，圣人畏因，凡人畏果
- 模型 + 指标，关注有效领先指标

### 三层递进
- **初阶**：选筹/定价
- **中阶**：融资/杠杆
- **高阶**：趋势/因果

## 五步分析框架 (五看)

### 第一步：看方向 (宏观 - 定性分析)

#### 经济周期四阶段
- **衰退期**：增长下行，通胀下行，流动性放松 → 债券为王
- **复苏期**：经济改善，通胀低位，流动性趋松 → 股票为王  
- **过热期**：增长上行，通胀上行，流动性趋紧 → 商品为王
- **滞胀期**：经济停滞，通胀高企，流动性收紧 → 现金为王

#### 核心指标
- 经济增长：GDP、社零、企业盈利
- 通货膨胀：CPI、PPI、工资增长
- 利率情况：实际利率、政策利率、流动性
- 债务情况：宏观杠杆率、家庭杠杆率

### 第二步：看行为 (中观 - 定量分析)

#### 市场情绪指标
- 成交量、融资融券、市场杠杆率
- 风险偏好：逐利vs避险资产选择
- 行为偏好：价值/成长/大中小盘风格

#### 资金流向
- 资本流向：美元指数、黄金、债市、股市、房地产、大宗商品
- 机会成本：长期国债收益率 vs 股债利差

### 第三步：看估值 (微观 - 定量分析)

#### 估值指标
- 市盈率/市净率历史百分位
- ROE > 15%，毛利率 > 50%，负债率 < 50%
- 股息率 vs 无风险收益率比较

#### 定价逻辑
- 定价 = 底价 + 溢价
- 底价由回报率（股息率/租金）决定
- 溢价由经济周期和市场情绪决定

### 第四步：看仓位 (实操 - 定量管理)

#### 仓位控制
- 高位震荡：20%仓位
- 低位震荡：80%仓位
- 定期再平衡策略

#### 风险管理
- 止盈止损原则
- 凯利公式：`f = (bp - q) / b`
- 杠杆系数控制

### 第五步：看时机 (实操 - 技术分析)

#### 三重时间滤网
- **季线**：定边界
- **月线**：定方向  
- **周线**：定机会
- **日线**：定时机

#### 技术指标
- BOLL、MACD、RSI组合验证
- 量价关系分析

## 经济周期与资产配置

### 衰退期策略
- **资产配置**：超配债券，低配股票，谨慎商品
- **防御为王**：重点配置长期国债和高评级信用债
- **现金管理**：保留10%-20%现金仓位

### 复苏期策略  
- **资产配置**：超配股票，低配债券，增配商品
- **股票重点**：周期性行业（金融、工业、可选消费）
- **成长配置**：适度配置成长股

### 过热期策略
- **资产配置**：超配大宗商品，低配债券与成长股
- **商品重点**：原油、工业金属为核心
- **周期股**：能源、材料等受益板块

### 滞胀期策略
- **资产配置**：超配现金及短债，超配黄金
- **防御配置**：保持高流动性应对政策突变
- **实物资产**：配置TIPS、房地产REITs等

## 投资决策OSCAR模型

### 目标设定
- 提升胜率和盈亏比

### 拆解维度
- 标的、价格、图形、估值、仓位

### 决策流程
1. **罗列清单**：经济周期、标的分类、技术指标、估值百分位
2. **获取数据**：多渠道数据收集
3. **归因判断**：交叉验证，决定是否下注
4. **执行操作**：根据信号执行买卖
5. **反馈迭代**：跟踪结果，优化策略

## 定价模型体系

### 现金流折现模型
```
V = C / (R - g)
```
- V：资产内在价值
- C：未来现金流之和  
- R：机会成本/无风险收益率
- g：现金流增长率

### 股票定价
- 股价 = 利润EPS × 市盈率PE
- 好公司特征：营收增长、毛利率提升、费用率降低
- 护城河排序：网络效应 > 技术/品牌 > 规模效应

### 债券定价
- 国债价格 = 名义利率 + 风险补偿
- 受经济增长预期、通胀预期、货币政策影响

### 大宗商品定价
- 底层逻辑：供需缺口 + 流动性变化
- 典型轮动：贵金属 → 工业金属 → 油气能源 → 化工 → 农产品

### 黄金定价
- 机会成本：收益率为零，抗通胀避险
- 定价因子：实际利率、美元汇率、地缘政治
- 实际利率 = 名义利率 - 通货膨胀率

## 实战要点

### 理财路径
收入 → 积累正现金流资产 → 现金流收入 → 消费

### 投资原则
- 顺势而为，选择比努力重要
- 应对比预测重要
- 不离场很重要，深耕一个行业
- 一切皆周期，除了经济周期和人性轮回

### 风险控制
- 杠杆率控制
- 流动性管理
- 期限配置
- 预期方向管理
