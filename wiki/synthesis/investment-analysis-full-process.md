# 投资分析全流程：从情报收集到动态预判

## 概述

本页面详细阐述了完整的投资分析流程，从L0情报收集到L5动态预判的五个层级分析体系。该体系强调基于边际变化进行假设验证，并通过反馈迭代不断完善投资决策。

## 分析流程框架

### 核心循环
```
变化 -> 假设 -> 验证 -> 反馈 -> 迭代
```

**关键洞察**：未来的价格取决于交易的边际力量，而边际力量来源于边际信息变化。

### 核心步骤
1. **基于边际新增变化**：数据、价格、事件、新闻等
2. **提出交易逻辑假设**
3. **定价推断及概率分布**
4. **交易行动 + 仓位管理**
5. **跟踪市场反馈**：市场价格反馈、客观事实确认、市场主观预期变化
6. **根据反馈调整**：超预期/符合预期/低于预期
7. **下一轮迭代**

## L1 常识判断 - 经验积累

### 个人段位
- **初阶**：选筹/估值
- **中阶**：融资/杠杆
- **高阶**：趋势/概率

### 个人修行
- 提高认知层次
- 完善思维框架
- 打造情报系统
- 积累资源禀赋
- 构建协作网络
- 磨砺心力

### 行业常识 - 面向未来&低买高卖
- **认知变现**：人永远无法赚取认知以外的钱
- **贝塔选择**：任何阿尔法的伟大胜利，都是建立在正确的贝塔选择之上
- **逆向思维**：买在无人问津时，卖在人声鼎沸处
- **分歧机会**：一致性预期越集中，市场将越接近走向反面

### 股市盈利方式
1. **赚中央银行的钱**：货币宽松推升估值，水涨船高
2. **赚企业成长的钱**：与优秀企业共同成长，分享红利
3. **赚交易对手的钱**：零和博弈，割韭菜

### 机构操盘识别
#### 关键信号
- 异常量价关系（突然放量&高位放量却滞涨）
- 筹码集中度（股东户数短期内大幅减少）
- 资金流向矛盾（大单净流入但股价下跌）
- 消息面配合（利好不涨&利空抗跌）
- 技术形态异常（大盘背离）

#### 操盘四阶段
1. **吸筹阶段**：低位建仓
2. **洗盘阶段**：低位震仓
3. **拉升阶段**：主升浪
4. **出货阶段**：高位震荡

### 市场预判 - 上察大势，下识人心
- **What**：现在是什么阶段？
- **Why**：为什么是这样状态？
- **How**：接下来应该如何应对？

#### 市场风格判断

- 强预期弱现实

## L3 定量分析 - 估值计算

### 核心公式
```
中国股市回报率 = 汇率（息差） + 利率（估值）+ 盈利增长率
```

### 估值指标
#### 盈利是因，估值是果
- 基本面/盈利 + 流动性/情绪 -> 估值
- 股价 = 每股收益 * 估值倍数

#### 主要指标
- PE市盈率百分位
- PB市净率百分位
- PS市销率百分位

### 偏离程度 - 均值回归
#### 移动均线系统
- MA10日：监测线
- MA20日：警戒线，买卖点，站上/跌破20日均线并且20日均线拐头往上往下
- MA60日：生死线
- MA120日：确认线
- MA250日：牛熊分界线，长期向上趋势标的，250线以下可以入场
- MA850日：中周期线，判断长期趋势和支撑阻力位

### 资产价格泡沫度估算
#### 房产：租售比
- 租金/房价，20年左右为正常水平，3%-5%合理，<0.5%逼近极限

#### 股票：市红率
- 分红/股价，3%-5%合理，<0.5%逼近极限

### DCF现金流贴现模型
```
P = Σ(CFt / (1+r)^t)

其中P为资产的评估值，CFt为资产在t时刻产生的现金流，r为反映预期现金流的折现率(资本成本)
```

### DDM股利贴现模型
```
V = Σ(Dt / (1+k)^t)

其中V为每股股票的内在价值，Dt是第t年每股股票股利的期望值，k是股票的期望收益率或贴现率
```

## L4 条件分析 - 底层逻辑

### 核心公式
```
利润 = 收入 - 成本
```

### 核心因子
- 供需、利率、通胀率、收益率

### 股价综合效应
股价是一种综合效应，核心在于盈利的预期变化。决定价格变化的根本原因是供给与需求的变化。

### 市场走势决定因素
- **短期**：预期
- **中期**：货币
- **长期**：经济基本面

### 宏观变化分析
#### 核心指标
- 周期、通胀、就业、增长、利率、信用、财政、M1、M2、社融、长期贷款

#### 观察结果
- 低利率、稳信用、宽财政 -> 衰退期

### 增长变化分析
#### 核心指标
- 盈利增长、十年国债收益率、石油、大宗

### 供需变化分析
如果投资者对未来经济走势乐观，就会去追求风险资产进行逐利，这会推升风险资产价格，长端利率上行，收益率曲线趋于陡峭。

如果投资者对未来经济预期悲观，就会去追求安全资产进行避险，这会导致风险资产价格下跌，美国十年国债收益率下降。

### 流动性变化分析
#### 核心指标
- 广义流动性：M2&社融&贷款
- 狭义流动性：银行间同业拆借利率&货币基金收益率、美元M2、金融业总资产

#### 流动性环境对估值的影响
- **充裕时**：投资者按想象力估值
- **中性时**：投资者按盈利进行估值
- **匮乏时**：稍有瑕疵估值都会被杀得很惨

### 利率变化分析
#### 核心指标
- LPR、基准利率、十年期国债收益率、二年期国债收益率

#### 基准利率
- 央行定价，资金成本、机会成本，影响支出总额(现金+信贷)

#### 十年期国债收益率
- 市场定价，无风险利率，社会融资成本之锚，资产定价之锚

#### 利率倒挂信号
- 若长期利率 < 短期利率，说明经济中的风险在增大，流动性紧张
- 美债利率倒挂(2年期 > 10年期)是经济衰退信号

### 通胀变化分析
#### 领先指标
- 石油价格、黄金价格、国债收益率

#### 滞后指标
- PPI、CPI、日常生活用品价格、食品能源价格

### 就业变化分析
- 美国就业数据强 -> 经济繁荣 -> 美联储加息 -> 利率上升 -> 股市下跌
- 美国失业率高 -> 经济衰退 -> 美联储放水 -> 流动性提升 -> 股市上涨

## L5 动态预判 - 概率分析

### 边际变化分析流程
1. **基于边际变化**（价格、数据、事件、新闻等）-> 提出交易假设
2. **预判概率分布 + 仓位控制** -> 采取交易行动
3. **跟踪市场反馈**（市场价格反馈、客观事实确认、市场主观情绪）-> 基于反馈来调整交易行为和仓位
4. **下一轮迭代**

### 博弈行为分析
不能只盯着自己的手牌，要开始关心对手，仔细观察对手的行为，根据对手的性格和风险偏好，去预判对手出牌的选择。

### 赢面赔率分析
```
赢面 = 赔率 * 胜率 - 败率
期望 = 胜率 * 赔率 * 本金
```

- **胜率**：判断方向，是盈还是亏？赢面有多大？
- **赔率**：判断收益，可以获得多高的收益率？可以赚多少倍？

### 凯利公式
```
f* = (bp - q) / b = (p(b+1) - 1) / b
```

其中：
- f* 为现有资金应进行下次投注的比例
- b 为投注可得的赔率
- p 为获胜率
- q 为落败率，即 1 - p

#### 凯利公式扩展
```
f* = (p*w - q*l) / (w*l)
```

其中w是获胜后的净赢率，l是净损失率。

#### 政府行为分析框架
```
政府行为 -> 政府判断 -> 市场规律
```

### 市场监测指标体系

#### 估值指标
- **深证平均市盈率**：主要在20到60倍之间波动，40是中位值
- 20倍左右：买入时机
- 60倍左右：卖出时机
- 20-40间：主买区间，参考M1增速
- 40-60间：主卖区间，参考M1增速

#### 流动性指标
- **M1-M2**：与上证指数呈现明显的正向关系
- M1 > M2：资金从沉淀中苏醒，需求强劲，交易活跃，经济景气度上升
- M1 < M2：资金从经济中沉淀，经济运行回落

#### 利率指标
- **国债收益 + 市盈率**：动态股息率小于10年国债收益率三分之一时卖出

### 市场生态系统分析

#### 参与者角色
- **巨兽**：定海神针，体量巨大，早期潜伏
- **机构**：稳扎稳打，择机而动
- **散户**：新鲜血液，易被收割
- **监管**：掌控节奏
- **媒体**：监管喉舌

#### 市场周期阶段
1. **低迷期**：较少数人参与，交易量稀拉
2. **准备期**：造势，大盘涨，监管布局，媒体造势
3. **调整期**：布局，大盘不涨，资金布局
4. **牛市头部期**：老玩家入场，题材热拱
5. **牛市中部期**：新人入场，妖股出现
6. **牛市尾部期**：大量散户入场，神奇论调
7. **收尾期**：蓝筹拉抬，掩护出货

### 市场心理博弈

#### 顶部套牢机制
- 洗脑式上涨 → 断崖式下跌 → 再次高速拉升
- 最终让人们像被钉在顶部一样，甘愿重仓吃整个熊市

#### 底部踏空机制
- 洗脑式下跌 → V型反弹 → 再次长阴暴跌
- 最终让人们像被钉在底部一样，甘愿空仓整个牛市

## 投资信仰与心态管理

### 信仰的力量
投资是一种信仰游戏，真正的信仰体现在：
- 在最狂热、最黑暗、绝大多数人都崩溃的时候，依然谈笑自如
- 无论外界环境如何变化，都始终如一地坚信
- 说到做到，意志和信仰之坚定，没有任何人、言论、走势可以摧毁

### 个人投资信仰示例
- 坚信企业和个股风险大 → 选择指数投资
- 坚信便宜的东西能挣钱 → 低买高卖
- 坚信价格走势有关键点位 → 在关键点位操作
- 坚信价格短期无序波动 → 用网格波段策略
- 坚信价格长期向上 → 用长期持仓等待胜利
- 坚信板块此起彼伏 → 做好配置
