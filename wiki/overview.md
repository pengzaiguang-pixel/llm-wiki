# LLM Wiki 总体概览

## 简介

LLM Wiki 是一个专门用于投资分析和资产配置的知识管理系统。它通过结构化的 Markdown 文件组织投资相关的知识，包括宏观经济分析、资产配置策略、风险管理方法、市场分析框架等内容。

- [[macro-economic-framework]] - 宏观经济分析四维框架
- [[asset-allocation-strategy]] - 大类资产配置策略
- [[macro-market-outlook-q2-2026]] - 2026年二季度宏观市场展望

## 核心知识体系

### 1. 投资分析框架
- **五步分析框架**：宏观方向、中观行为、微观估值、仓位管理、时机选择
- **概率分析**：胜率、赔率、交易频率的系统性分析
- **OSCAR模型**：目标、拆解、清单、获取、归因、决策的完整流程

### 2. 资产配置理论
- **美林时钟**：经济周期与资产配置的经典理论
- **分散化原则**：通过资产、市场、时间的分散降低风险
- **动态再平衡**：根据周期调整资产配置比例

### 3. 风险管理体系
- **风险评估**：波动率、最大回撤、夏普比率等指标
- **风险控制**：仓位管理、止损止盈、压力测试
- **风险偏好**：保守型、稳健型、积极型的分类管理

### 4. 市场分析方法
- **技术分析**：BOLL、MACD、RSI等技术指标
- **基本面分析**：估值、盈利、成长性等基本面因素
- **量化分析**：统计套利、因子模型、回测验证

## 知识关联关系

### 宏观经济分析 → 资产配置策略
- 经济周期判断影响大类资产配置
- 政策环境变化影响风险偏好
- 流动性环境影响资产价格

### 投资理论 → 分析方法 → 实践应用
- 投资理论指导分析方法选择
- 分析方法应用于具体实践
- 实践经验反馈理论优化

### 指标监控 → 趋势判断 → 策略制定 → 风险控制
- 实时监控关键指标变化
- 基于数据判断市场趋势
- 根据趋势制定投资策略
- 通过风险管理控制下行风险

## 使用指南

### 查询信息
1. 从 [[index]] 页面查看所有可用页面
2. 使用页面内的内部链接导航
3. 查看相关页面的引用关系

### 更新知识
1. 添加新的源文档摘要到 sources/
2. 更新相关实体页面
3. 在综合分析页面整合新信息
4. 更新索引和日志文件

### 维护建议
1. 定期审查实体页面的准确性
2. 保持分析页面的时效性
3. 维护知识关联的完整性
4. 确保内容的专业准确性
