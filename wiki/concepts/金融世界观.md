# 金融世界观

## 概述
金融世界观是理解金融市场运行规律和投资方法的系统性认知框架。

## 核心认知
### 价格函数
价格=f (成交量，时间，空间，人，认知)

### 无套利均衡
金融市场定价 = 成本 + 时间价值 + 机会补偿
资产定价 = 预期( 基本面 + 政策面 -> 边际新增 ) + 风险偏好(流动性 + 情绪 )

边际新增(客观事实 + 数据) -> 主观偏见 + 情绪放大器 -> 市场集体投票 -> 市场价格

## 认知与工具
### 量化思维
底层逻辑 -> 分析框架 -> 量化模型 -> 核心参数 -> 数据/消息支撑

### 批判性思维
对事实和数据、推理逻辑及结论保持适度警惕和质疑，有助于得出胜率更高的结论。

## 投资哲学
### 三阶段理论
价值投资 -> 经济周期 -> 政治博弈 -> 历史规律 -> 人性回归

### 时间维度
投资长期看人口，中期看政策，短期看金融。

## 市场本质
- 未来的价格取决于交易的边际力量，而边际力量来源于边际信息变化
- 价格的波动来源于市场预期的变化，市场预期的变化又来源于参与者主观对未来推测假设的看法的变化
- 金融市场不是直接与客观事实相关联，而是与主观偏见相关联
