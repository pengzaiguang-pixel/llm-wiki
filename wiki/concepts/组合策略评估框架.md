# 组合策略评估框架

## 定义
一套系统性的投资组合评估体系，通过定量指标对策略的风险、收益、稳健性进行综合评分，用于识别和筛选优质的资产配置策略。

## 核心理念
夏普高 + 回撤小 + 长期稳定 = 真正优秀的组合

## 详细评估标准

### 基础标准
- **年化夏普率** ≥ 1.2，**卡玛比率** ≥ 1.0
- **最大回撤** ≤ 12%，**回撤修复时间** ≤ 6 个月
- **年化收益率**：8%-15%
- **年化波动率**：5%-10%
- **胜率** ≥ 55%，**盈亏比** > 2.0
- **斜率** > 0，**置信度** > 90%

### 权重分配
- **收益能力**：30%
- **风险控制**：35%
- **风险收益性价比**：25%
- **长期稳健性**：10%

### 总分评级标准
| 分数范围 | 评级 | 特征 |
|---------|------|------|
| 90-100 | 顶级策略 | 机构旗舰级，夏普高、回撤小、长期可规模化 |
| 80-89 | 优秀策略 | 专业对冲基金水平，可管理大资金 |
| 70-79 | 良好策略 | 合格主动基金，性价比不错 |
| 60-69 | 一般策略 | 能赚钱但不稳，需优化风控 |
| 50-59 | 较差策略 | 风险收益不匹配，不如指数基金 |
| <50 | 劣质策略 | 高波动低收益，本质赌性强 |

## 四维度评估体系

### 1. 收益能力（30分）
基于年化收益率（默认周期≥3年）
- ≥15% → **30分**
- 12-14.9% → **25分**
- 9-11.9% → **20分**
- 6-8.9% → **15分**
- 3-5.9% → **8分**
- <3% → **0分**

### 2. 风险控制（35分）

#### 最大回撤（20分）
- ≤8% → **20分**
- 8.1-12% → **16分**
- 12.1-18% → **12分**
- 18.1-25% → **6分**
- >25% → **0分**

#### 最大回撤评级
- <5%：极度稳健（固收+、低风险组合）
- 5-12%：优秀（专业机构、对冲基金合格线）
- 12-20%：一般偏上（能接受，但压力巨大）
- 20-30%：偏高风险（纯股票多头常见）
- >30%：高危/垃圾（容易清盘风险）

#### 年化波动率（10分）
- ≤8% → **10分**
- 8.1-12% → **8分**
- 12.1-18% → **5分**
- 18.1-25% → **2分**
- >25% → **0分**

#### 单日最大亏损（5分）
- ≤1.5% → **5分**
- 1.6-3% → **3分**
- >3% → **0分**

### 3. 风险收益性价比（25分）

#### 年化夏普率（15分）
- ≥1.5 → **15分**
- 1.2-1.49 → **12分**
- 0.9-1.19 → **9分**
- 0.6-0.89 → **5分**
- <0.6 → **0分**

#### 夏普率评级
- <0.5：差（不如买国债）
- 0.5-0.8：一般（能赚钱但波动大）
- 0.8-1.2：良好（合格主动基金）
- 1.2-1.8：优秀（机构级优质策略）
- >1.8：顶级（极难长期维持）

#### 卡玛比率（10分）
- ≥1.5 → **10分**
- 1.2-1.49 → **8分**
- 0.9-1.19 → **6分**
- 0.6-0.89 → **3分**
- <0.6 → **0分**

### 4. 长期稳健性（10分）

#### 回撤修复时间（5分）
- ≤3个月 → **5分**
- 3-6个月 → **4分**
- 6-12个月 → **2分**
- >12个月 → **0分**

#### 年度正收益占比（5分）
- 100%（年年正）→ **5分**
- 80-99% → **4分**
- 60-79% → **2分**
- <60% → **0分**

## 关键洞察
1. **夏普看性价比，卡玛看生存能力**：回撤小、修复快、卡玛高 → 真正的顶级组合
2. **波动率必须与收益匹配**：夏普≥1才算波动率"值得"
3. **长期稳定性至关重要**：3年以上夏普才有参考价值
4. **风控第一**：回撤太大说明仓位管理失控，修复时间长说明策略失效

## 应用
该评估框架可应用于：
- 投资组合的绩效评估
- 基金产品的筛选和比较
- 量化策略的开发和优化
- 风险管理体系的建立
