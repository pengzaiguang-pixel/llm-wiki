# 估值方法

## 定义
估值方法是指用于确定资产内在价值的一系列分析技术和工具。在投资领域，估值方法帮助投资者判断资产价格是否合理，从而做出明智的投资决策。

## 详细说明

### 绝对估值法
#### 现金流折现模型 (DCF)
- **定义**：基于资产未来现金流的现值来估算其内在价值
- **公式**：DCF = Σ [CFt / (1 + r)^t]，其中 CFt 是第 t 年的预期现金流，r 是折现率
- **应用场景**：适用于现金流稳定的公司估值
- **优点**：理论上最接近内在价值
- **缺点**：对参数敏感，预测难度大

#### 股利折现模型 (DDM)
- **定义**：基于股票未来股利的现值来估算股票价值
- **戈登增长模型**：P = D1 / (r - g)，其中 D1 是下一年度股利，r 是要求回报率，g 是增长率
- **适用对象**：稳定分红的公司

### 相对估值法
#### 市盈率 (PE)
- **定义**：股价与每股收益的比率，反映投资者愿意为每单位盈利支付的价格
- **计算**：PE = 股价 / 每股收益 = 总市值 / 净利润
- **分类**：
  - **静态PE**：基于过去12个月的实际收益 (TTM)
  - **动态PE**：基于预期未来收益
- **适用性**：盈利稳定的成熟企业
- **局限性**：不适用于亏损或盈利波动大的公司

#### 市净率 (PB)
- **定义**：股价与每股净资产的比率，反映股东权益的市场价值
- **计算**：PB = 股价 / 每股净资产 = 总市值 / 净资产
- **适用性**：资产密集型行业，如银行、房地产
- **局限性**：不适用于轻资产或无形资产较多的公司

#### 市销率 (PS)
- **定义**：股价与每股营业收入的比率
- **计算**：PS = 股价 / 每股收入 = 总市值 / 营业收入
- **适用性**：初创公司或尚未盈利但有收入的公司

#### 市现率 (PCF)
- **定义**：股价与每股现金流的比率
- **计算**：PCF = 股价 / 每股现金流
- **优势**：现金流较难操纵，相对更可靠

### 资产基础法
#### 净资产价值法
- **定义**：基于公司净资产价值进行估值
- **调整**：对资产账面价值进行公允价值调整
- **适用性**：拥有大量实物资产的公司

#### 清算价值法
- **定义**：假设公司立即清算时的资产变现价值
- **用途**：评估公司的底线价值

### 行业特定估值法
#### EV/EBITDA (企业价值倍数)
- **定义**：企业价值与息税折旧摊销前利润的比率
- **计算**：EV/EBITDA = (市值 + 净债务) / EBITDA
- **优势**：消除资本结构和会计政策影响

#### PEG (PE增长率)
- **定义**：市盈率与盈利增长率的比率
- **计算**：PEG = PE / 盈利增长率
- **判断标准**：PEG = 1 为合理估值，PEG < 1 为低估

### 历史比较法
#### 历史百分位
- **定义**：当前估值在历史数据中的位置
- **应用**：
  - 0%-20%：极度低估
  - 20%-40%：低估
  - 40%-60%：合理估值
  - 60%-80%：高估
  - 80%-100%：极度高估

#### 历史均值回归
- **理论**：估值长期向历史均值回归
- **应用**：基于长期均值判断当前估值水平

### 估值区间方法
#### 保守估值
- **方法**：使用较为保守的假设和参数
- **目的**：确保安全边际

#### 乐观估值
- **方法**：使用较为乐观的假设和参数
- **目的**：判断潜在上涨空间

#### 合理估值区间
- **方法**：综合多种估值方法的结果
- **目的**：得出合理的估值范围

### 投资星级系统
#### 星级定义
- **1星**：泡沫阶段（高估），市场风险较高
- **2星**：偏高估
- **3星**：正常估值
- **4星**：偏低估
- **5星**：投资价值最高阶段（低估），市场机会较好

#### 颜色编码系统
- **绿色**：低估，适合投资
- **黄色**：合理估值，观察状态
- **红色**：高估，谨慎对待

## 应用场景
- 股票投资决策
- 企业并购定价
- 基金选择
- 资产配置
- 风险评估
