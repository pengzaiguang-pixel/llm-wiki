# 投资概率分析

## Overview
投资概率分析是一种基于数学概率理论的投资决策方法，通过计算不同投资结果的可能性及其对应的收益或损失，来评估投资策略的期望值。

## Details
投资概率分析的核心是期望值计算，公式为：`期望收益 = Σ(每种结果的概率 × 该结果的收益)`

关键要素包括：
- 胜率（p）：投资成功的概率
- 赔率（b）：投资成功时的收益与失败时的损失比
- 交易频率：单位时间内进行交易的次数
- 凯利公式：f = (bp - q) / b，用于确定最优下注比例

在投资实践中，概率分析强调：
1. 只有当期望值为正时才进行投资
2. 通过分散投资降低非系统性风险
3. 控制单笔投资的损失幅度
4. 通过足够多的交易次数实现概率优势
